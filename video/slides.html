How we built it

WorkBuddy as our independent tester.

Blind held-out tests

Given only the bank's test data and the outcome rules, it wrote 40 test cases, blind to our prompts.

It caught a real bug

Each set was run once, untuned. Set 2 found a share buy from the wrong default account; that became a deterministic rule.

Tip: one well-specified job

Test cases from a spec, with a clear output format: back within half an hour. Open-ended coding tasks stalled.

Tip: a second AI as your tester, not just your coder

The app itself: written with Claude Code, every change reviewed, over 1,300 automated tests.
